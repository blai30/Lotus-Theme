# Lotus Theme Changelog

## Unreleased

## 2.1.0 - 2026-10-30

### Changed

- Require IDE version 2025.3 or newer. Both themes build on the Islands themes, which earlier versions don't have.
- Color schemes no longer override your editor and console font, font size, line spacing, or ligature settings.
- Polish the IDE UI in both themes with one Lotus pink accent for selections, checkboxes, links, focus rings, progress bars, default buttons, and the selected tool window button.
- Popups, menus, and tooltips now stand apart from the editor, and toolbar buttons no longer sit on dark boxes.
- Project tree file colors and the run/debug controls now use Lotus colors instead of stock browns, greens, and reds.
- Buttons now use rounded corners to match the rest of the Islands UI.

### Removed

- Remove color scheme entries for the discontinued Markdown Navigator plugin.

## 2.0.1 - 2026-07-10

### Fixed

- Fix Islands theme background inconsistency causing visible seams around the tool window stripe, main toolbar, and status bar.
- Lotus Dark: Fix an abnormally bright unfocused title bar and disabled dropdown backgrounds.
- Lotus Light: Fix an abnormally bright unfocused title bar and disabled dropdown backgrounds.

### Changed

- Lotus Dark: Darken the main window background so it blends better with the Islands theme.
- Lotus Dark: Darken the editor background and tune tree view selection colors for better contrast.
- Lotus Light: Lighten the tree view selection background for both focused and unfocused states.
- Lotus Light: Darken the modified file text color in the project view for better contrast.
